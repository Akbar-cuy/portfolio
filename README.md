# Akbar Maulana Setiawan — Portfolio

A responsive personal portfolio website showcasing my experience, skills, certifications, and project case studies in business analysis, product strategy, and UX research.

**Live website:** [akbarmaulana.site](https://akbar-cuy.github.io/portfolio/)

## Features

- Responsive single-page layout with Home, About, Skills, Certification, Projects, and Contact sections
- Animated role text and an interactive particle background
- Scroll-triggered animations
- Keyboard-accessible certification and project detail dialogs
- Downloadable CV
- Links to LinkedIn, GitHub, Instagram, and email

## Built with

- HTML, CSS, and vanilla JavaScript
- Bootstrap 5
- Font Awesome
- Typed.js, AOS, jQuery, and ScrollReveal

Third-party libraries are loaded from CDNs in `index.html`. There is no build step or package installation.

## Run locally

1. Clone or download this repository.
2. Open the project folder in your editor.
3. Open `index.html` in a browser, or serve the folder with a local static web server (for example, the Live Server extension in VS Code).

Keep the original folder structure when running the site so its styles, scripts, CV, icons, and images resolve correctly.

## Project structure

```text

├── index.html                    # Main portfolio page and case-study content
├── style.css                     # Page styles and responsive layout
├── app.js                        # Particle background setup
├── particle.js                   # Particle animation implementation

```
